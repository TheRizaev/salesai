Как получить API ID и API Hash?

  1. Перейдите на my.telegram.org
  2. Войдите с помощью вашего номера телефона
  3. Нажмите "API development tools"
  4. Заполните форму (можно указать любые данные)
  5. Скопируйте api_id и api_hash
